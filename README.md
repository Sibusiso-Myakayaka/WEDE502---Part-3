Glen Austin Sports Club Website

1. Project Overview
The Glen Austin Sports Club website is a website developed to provide information about the club and its sporting activities.
The club is based in Glen Austin, Midrand, Gauteng. It was established in 2018 as a community sports initiative.
The website will help visitors learn about the club, explore available sports, view photographs, find contact information and submit enquiries.

3. Project Objectives
The main objectives of the website are to:
Provide information about Glen Austin Sports Club.
Introduce visitors to the available sports and activities.
Display club photographs in a gallery.
Share information about membership and joining the club.
Allow visitors to contact the club.
Allow visitors to submit enquiries through an online form.
Make information easy to find on different devices.

5. Technologies Used
The following technologies were used to develop the website:
HTML5: Used to structure the website pages.
CSS3: Used to style the pages, colours, layouts and navigation.
JavaScript: Used to add interactive features such as form validation, image viewing and search functions.
Leaflet: Used to display the interactive map.
OpenStreetMap and CARTO: Used as map data and tile providers.
Formspree: Used to process website form submissions and send enquiries by email.
Google Fonts: Used for the Montserrat and Open Sans fonts.

6. Website Features
The website includes:
Responsive navigation menu.
Interactive image gallery with a lightbox.
Sports search and filtering.
Contact form with input validation.
Enquiry form with email submission.
Success and error messages after form submission.
Interactive map showing the Glen Austin area.
Smooth scrolling and page animations.

8. How to Open the Website
To view the website on a computer:
Download or clone the project repository.
Extract the project folder if it was downloaded as a ZIP file.
Open the project folder.
Locate `index.html`.
Open `index.html` using Google Chrome or another web browser.
Use the navigation menu to explore the website.
An internet connection is required for external services such as Google Fonts, Formspree and the interactive map.
